# Add your first client

A client record stores who you bill and how. Add one under **Clients → New client**, and you can reuse it on every future invoice. In the app these records are labelled "customers".

## How do I add a client?

1. Select **Clients** in the left sidebar.
2. Select **New client**.
3. Fill in at least the name and one email address.
4. Select **Save client**.

You can start an invoice for the client right away with **Create invoice**, or return to the list.

## Which fields can I fill in?

| Field | Notes |
| --- | --- |
| Name | Required. The person you deal with |
| Company | Optional. Shown on the invoice if filled in |
| Email addresses | Up to 3 billing contacts. All of them receive invoices |
| Phone | Optional |
| Address | Printed in the "Bill to" block |
| Currency | USD by default; 30+ currencies available |
| Default payment terms | Overrides the account default for this client |
| Tax ID | Printed on invoices for this client |
| Notes | Private. Clients never see them |

The first email address is the main contact. Any extra addresses receive the same invoice emails, receipts and reminders.

## Why does the currency matter?

Currency is set per client, not per invoice. Every invoice for the client uses it, and the payment page shows amounts in that currency. Choose it carefully before the first invoice. If you change it later, existing invoices keep the currency they were created with, and only new invoices use the new one.

## What are the plan limits?

The Free plan allows up to 3 clients. Pro and Business have no limit. If you have a long list of clients in a spreadsheet, see "Import data from spreadsheets".

## What can I do with a client later?

- **Edit** any field. Changes affect future invoices, not sent ones.
- **Archive** a client to hide them from lists and the invoice form. History and reports are kept, and you can restore the client at any time.
- **Delete** a client, which is only possible if they have no invoices.

Clients also get a secure client portal link, where they can see all their invoices and pay without a password. They sign in with a magic link sent to their email. You do not need to set anything up for this.

If a client's email changes, edit the record before sending the next invoice, because past invoices are not re-sent automatically.
