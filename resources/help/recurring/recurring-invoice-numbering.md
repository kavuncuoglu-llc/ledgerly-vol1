# How recurring invoices are numbered

Invoices generated by a recurring schedule use the same numbering as every other invoice in your account. There is no separate sequence for recurring invoices.

## How does Ledgerly assign the number?

When a schedule runs, the new invoice takes the next number in your account's sequence. If your last invoice was INV-4470, the next generated invoice is INV-4471, whether it comes from a schedule or from you clicking **New invoice**.

This means numbers from different schedules and one-off invoices interleave. If three schedules all run on the 1st of the month, they receive three consecutive numbers, in the order the runs are processed.

## Where do I change the prefix or next number?

Go to **Settings → Invoices**. There you can edit:

- **Invoice prefix**, for example changing INV- to LGR-
- **Next invoice number**, the number the next invoice will receive

Changes apply to invoices created from then on, including those from recurring schedules. Existing invoices keep the numbers they already have.

Set the next number higher than any number you have used. Ledgerly will not let you save a number that is already taken.

## Are numbers reused if I delete or void something?

No. Numbers are never reused.

- A **Void** invoice keeps its number and stays in your records.
- A deleted draft that was created by a schedule also leaves a gap, because its number was assigned when it was generated.

Gaps in the sequence are normal and expected. If your accountant asks about a missing number, look for a deleted draft or check the Void filter on the Invoices list.

## Can I give a schedule its own prefix?

No. The prefix is account-wide. If you want to tell recurring invoices apart at a glance, add a reference in the schedule's **Invoice title** or **Notes to client** field, such as "Monthly retainer, July". The Invoices list can also be filtered to show only invoices created by recurring schedules.

## What happens when two schedules run at the same time?

Each run is processed one at a time, so two invoices can never get the same number. If you pause a schedule, no numbers are consumed. If a run fails before the invoice is created, no number is consumed either. See What happens when a recurring run fails.

## Can the number change after the invoice is created?

Not automatically. You may edit the number of a Draft before sending. Once an invoice has been sent, its number is fixed so that your client's records and payment references still match.
