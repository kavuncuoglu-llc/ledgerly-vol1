# Add a client

To add a client, open **Clients** in the left sidebar and click **New client**. Only a name is required, but adding an email lets you send invoices straight away. In the app, clients are called "customers".

## How do I create a client?

1. Click **Clients** in the sidebar.
2. Click **New client**.
3. Fill in the details (see the table below).
4. Click **Save client**.

You can also create a client on the fly from the invoice form: in the **Client** field, type a new name and choose **Add new client**.

## What information can I store?

| Field | Notes |
|---|---|
| Name | Required. The contact person or the client name |
| Company | Shown on invoices when filled in |
| Email(s) | Up to 3 billing contacts. See Multiple billing contacts for a client |
| Phone | Optional |
| Address | Printed on invoices and statements |
| Currency | USD by default. 30+ currencies are available |
| Default payment terms | Net 30 by default. Used for new invoices |
| Tax ID | Printed on invoices. See Tax IDs for clients |
| Notes | Private notes only you and your team can see |

## Is there a limit on how many clients I can add?

It depends on your plan:

- **Free:** up to 3 clients.
- **Pro and Business:** unlimited clients.

Archived clients still count toward the Free plan limit. If you reach it, you will be asked to upgrade or delete a client that has no invoices.

## Which fields should I fill in first?

Start with name and email. Without an email, you can still create an invoice and download the PDF, but you cannot email it or use Auto-send on a recurring schedule. Set the currency before you create the first invoice, since each invoice uses the client's currency when it is created.

## Can I add a client from a spreadsheet?

Yes. If you have many clients, import them in one go instead of entering them one at a time. See Import clients from CSV.

## What happens after I save?

The client opens on their own page, showing a summary and an empty invoice list. From there you can click **New invoice**, send the portal link (see Client portal), or set up a recurring schedule for them under **Recurring**.

**Who can add clients?**

On the Business plan, Owners, Admins and Members can all add clients. Free and Pro accounts have a single user.

**What if I make a mistake?**

Open the client and click **Edit** to change any detail. Changes affect new invoices only. Invoices that were already sent keep the details they had when sent. See Edit, archive or delete a client.
