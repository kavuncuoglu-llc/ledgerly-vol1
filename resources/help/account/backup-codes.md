# Backup codes

Backup codes let you sign in when you cannot get a code from your authenticator app or phone. You receive 10 single-use codes when you turn on two-factor authentication.

## What do backup codes look like?

Each code is a short string of letters and numbers, such as `k4m9-x2pq`. Every code works exactly once. After you use it, it is crossed off the list and cannot be used again. Backup codes are only available if two-factor authentication is on.

## Where do I find my backup codes?

Ledgerly shows the codes immediately after you verify two-factor authentication. You can see how many are left at any time:

1. Open **Settings → Account → Security**.
2. Under **Two-factor authentication**, select **Backup codes**.
3. Enter your password.

For safety, the page shows the number of unused codes and lets you generate a new set. It does not show the old codes again after the first time.

## How do I store them safely?

Treat them like a spare key. Good options:

- A password manager's secure notes
- A printed copy in a locked drawer or safe
- A file in an encrypted folder

Do not keep them in an email to yourself, a shared document or a screenshot on your phone's photo roll. Anyone with your password and a backup code can sign in.

## How do I sign in with a backup code?

1. Enter your password as usual.
2. On the code prompt, select **Use a backup code**.
3. Type one unused code and select **Verify**.

The code is used up as soon as you submit it. After signing in, Ledgerly reminds you how many remain. If you have 3 or fewer, it shows a banner suggesting you generate a new set.

## How do I generate a new set?

Select **Generate new codes** on the Backup codes page and confirm with your password. This creates 10 new codes and immediately invalidates all older ones, whether used or not. Make sure you save the new list before closing the page. You can generate a new set as often as you like.

## What if I run out of codes and lose my device?

Without your authenticator or a backup code, you cannot complete sign-in yourself. Email support@ledgerly.example from the address on your account. We will ask questions to confirm it is you, such as your business name, recent invoice numbers and the plan you are on. Once verified, we turn off two-factor authentication so you can sign in and set it up again.

Team members on the Business plan each have their own set of codes. An Owner cannot view them.
